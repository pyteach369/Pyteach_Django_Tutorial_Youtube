## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Git
- Python version compatible with the project
- [uv](https://docs.astral.sh/uv/getting-started/installation/)

### 1. Clone the repository

```bash
git clone https://github.com/pyteach369/Pyteach_Django_Tutorial_Youtube.git
cd Pyteach_Django_Tutorial_Youtube
```

### 2. Install project dependencies

```bash
uv sync
```

This command creates or updates the project's virtual environment and installs the dependencies defined by its configuration and lockfile.

### 3. Apply database migrations

```bash
uv run python manage.py migrate
```

### 4. Start the Django development server

```bash
uv run python manage.py runserver
```

Open your browser and visit:

http://127.0.0.1:8000/

**Note:** These instructions assume that `pyproject.toml`, `uv.lock` (if committed), and `manage.py` are located in the expected project structure. Follow the relevant tutorial if your project uses a different layout.
